# 跟进记录：

## 1. 应生成跟进记录的操作

下表中的类型为业务分类，同一类型可以根据操作显示不同节点名称。

| 触发操作                                     | 节点名称    | 节点内容字段                                               |
| ---------------------------------------- | ------- | ---------------------------------------------------- |
| 保存修改责任认定成功                               | 责任认定    | 第一联系人、投诉时间、未达成原因、客户陈述、责任部门、售后类型、责任人、责任原因、处理结果、附件     |
| 跟进处理选择“方案未达成一致”，保存成功                     | 方案未达成一致 | 沟通结果、未达成原因、沟通内容、图片；存在时效配置时展示处理时效、本轮开始、处理截止和本轮结束信息    |
| 跟进处理选择“已确认退赔方案”，确认成功；或调整已有方案后重新确认成功      | 已确认退赔方案 | 处理方式、退款信息、商品置换信息、收款信息、方案附件；完整字段见第 4 节。调整后保存新快照，保留旧方案 |
| 保存普通跟进成功                                 | 沟通跟进    | 沟通内容、图片；编辑过的记录展示修改时间，并保留修改历史                         |
| 财务提交执行结果，或收到有效付款结果回执                     | 财务付款    | 付款结果、实际金额、交易流水号、失败原因、付款凭证；有实际备注时展示付款说明               |
| 采购提交实际发货或交付结果，或收到有效发货回执                  | 采购发货    | 发货方式、发货内容（商品及本次数量）、物流单号或交付单据号、备注、附件；每个实际发货批次分别记录     |
| 客服提交复核结果成功                               | 客服复核    | 复核结果、客户反馈、复核说明、附件（有提交时）                              |
| 跟进处理选择“无赔付直接结案”，确认成功                     | 无赔付直接结案 | 结案说明；操作人和结案时间由公共信息展示                                 |
| 通过其他有效结案入口确认结案成功，包括责任认定选择“已解决，立即结案”并成功保存 | 结案      | 结案说明、已记录的附件（如有）；操作人和结案时间由公共信息展示                      |

### 责任认定节点的展示要求

- 责任认定是时间线中的节点，按发生时间排列，不放在时间线顶部作为独立固定区块。
- 按表单顺序完整展示第一联系人、投诉时间、未达成原因、客户陈述、责任部门、售后类型、责任人、责任原因、处理结果、附件。
- 未填写的内容显示“未填写”，没有附件显示“无”；闭店免填责任人时显示“无需填写”。
- “归因参考”属于表单辅助提示，不作为用户提交的业务字段；占位文字、必填星号、上传限制也不写入记录内容。
- 节点时间和操作人取本次认定的保存信息，不能混用客户投诉时间或当前登录人。
- 历史节点读取当次保存的内容，不用工单当前值补写历史内容。历史缺失字段如实显示未填写或未记录。

## 2. 不进入跟进记录的操作

| 操作或状态                    | 展示或记录位置                   |
| ------------------------ | ------------------------- |
| 创建工单、收到投诉、客服接单、开始处理      | 工单信息、处理流程、操作日志            |
| 修改客诉等级、AI 识别或调整等级        | 工单信息、处理流程或操作日志            |
| 关联或调整客户、关联或调整订单          | 工单信息、操作日志                 |
| 分派、转交、内部流转               | 处理流程、操作日志                 |
| 财务审批、采购审批，包括通过、驳回及审批意见   | 审批记录、处理流程；列表按既定规则展示审批处理结果 |
| 待付款、付款处理中、待发货、待复核等纯等待状态  | 处理流程、列表状态；不作为实际执行结果写入跟进记录 |
| 字典、AI 开关、等级规则、处理时效等配置修改  | 配置模块、配置日志                 |
| 查询、打开详情、查看附件、切换 Tab、关闭抽屉 | 不生成业务跟进节点                 |
