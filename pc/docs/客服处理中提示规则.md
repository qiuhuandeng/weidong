# 客服处理中提示规则

显示内容指投诉列表「工单进度」列。

| 触发动作                          | 显示内容                                         |
| ----------------------------- | -------------------------------------------- |
| 客服接单                          | 客服已接单；下方显示「接单人：姓名」                           |
| 客服填写未达成原因并保存                  | 客服处理中；下方显示所选原因原文，例如「无法联系上客户」                 |
| 客服修改当前未达成跟进的原因                | 下方更新为修改后的原因；编辑更早的历史跟进不改变当前提示                 |
| 客服确认含退款的解决方案并提交审批             | 财务审批中；下方显示「处理中」                              |
| 财务拒绝 / 驳回审批                   | 客服处理中；下方红字显示「财务驳回」                           |
| 钉钉审批撤回 / 撤销成功                 | 客服处理中；下方显示「审批已撤销」                            |
| 驳回或撤销后，客服重新填写未达成原因            | 客服处理中；下方显示新原因，替换原驳回或撤销提示                     |
| 客服调整方案或保留原退款方案，重新提交           | 财务审批中；下方显示「处理中」                              |
| 客服填写或修改责任认定，选择「未解决，继续沟通」      | 下方显示责任认定中填写的未达成原因；已有这些进展时保持对应提示，不显示「已填写责任认定」 |
| 客服补充普通跟进、回复客户或修改等级            | 原状态及下方提示不变                                   |
| 客服确认结案，或责任认定选择「已解决，立即结案」并保存成功 | 已结案；不再显示原进度提示                                |
| 尚未填写原因，且没有审批退回等进展             | 只显示「客服处理中」，下方不显示提示                           |
